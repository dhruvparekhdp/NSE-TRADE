## Built

### C17 (`engine/paper_jobs.py`, `engine/runner.py`, `005_paper_runs.sql`)
- **C17.1** Pending + open count toward `max_open_swing`; reserve slot on queue.
- **C17.2** One position per symbol → `already_in_symbol`.
- **C17.3** Wallet debited/credited on CNC buy/sell; `cash` skip uses wallet only.
- **C17.4** `daily_bars_ready`; chain after `job_daily_bars`; cron retries if bar late.
- **Follow-up (Claude review)**  
  - **Equity sizing:** `equity_at_cost()` = cash + holdings at cost for `size()`; wallet only for affordability.  
  - **Pending terminal states:** every fill attempt sets final status (`filled`, `no_fill`, `cash`, sizing reason, `no_bar`); `load_portfolio_state` counts pending with `trade_date >` scan date only.  
  - **Idempotency:** `paper_runs(trade_date, job)` — `eod_fill` / `scan` run once per day; 16:15/16:20 are no-ops after the daily-bars chain.
