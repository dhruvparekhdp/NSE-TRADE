# C17 + C13 — paper book correctness and market filter

Branch: `feat/c17-paper-book` (from `feat/v8-complete`) · **Not merged to `main`.**

## Built

### C17 (`engine/paper_jobs.py`, `engine/runner.py`)
- **C17.1** `load_portfolio_state` counts pending orders; `_reserve_swing_slot` after each queued pending in `job_scan`.
- **C17.2** Second strategy on same symbol → `skip_reason=already_in_symbol` (first enabled strategy wins).
- **C17.3** CNC buy debits wallet (notional + buy charges + slip) at fill; exit credits sell proceeds − charges; insufficient cash → `skip_reason=cash`. Portal equity unchanged formula (cash + marked positions).
- **C17.4** `daily_bars_ready`; `job_eod_fill` / `job_scan` no-op until bar exists; `job_daily_bars` chains fill + scan; 16:15 / 16:20 jobs remain as retry.

### C13
- `market_filter`: **on** (default) | **off** (paper: take picks, `would_skip_reason` in features) | **shadow** (no pending).
- Live + `off` refused in `validate_setting`; portal whitelist + badge (`FILTER OFF` / `OPEN` / `CLOSED` / `SHADOW`).
- Default meta/rules `market_filter` → `"on"`.
