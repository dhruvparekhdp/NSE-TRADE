# NSE-002 handoff — admin / HTTP lockdown

## Summary

The portal now refuses to listen on a non-loopback address unless `EXPOSE_HTTP=true`.
Every admin route returns 401 unless the caller has the session cookie or an
`Authorization: Bearer` token that matches `ADMIN_TOKEN`. Login compares the
passcode in constant time and returns 429 after five failures in ten minutes.
`docs/remote-access.md` says how to reach the box (Tailscale, WireGuard, or an
HTTPS reverse proxy) and says not to publish plain HTTP.

This branch was created from `main` (`aae5f1f`). The ticket asked for
`jarvis/NSE-002`; the branch is `jarvis/nse-002` (lowercase). NSE-003 was
already committed and pushed on `jarvis/nse-003` (`5867aa0`) before this work
started. This branch does not contain NSE-001 or NSE-003.

This change does not place orders, does not log in to Angel, and does not
change `mode` or `live_orders` (both stay paper / false).

## Assumptions

- `GET /api/health` and `POST /api/login` stay unauthenticated. Health is a local probe and returns no secrets. Login is the auth endpoint.
- Market read APIs (`/api/market`, `/api/paper`, `/api/quotes`, and the other portal reads already marked non-admin) stay open. They are only safe because the process binds localhost. The remote-access note says not to publish the port.
- Admin routes are: `/api/books`, `/api/today`, `/api/strategies`, `/api/kill`, `/api/keys` and its posts, `/keys`, `/api/settings`, `/api/tables`, `/api/quotes/refresh`, `/api/universe/exclude`, including the same paths under `/nse`.
- `ADMIN_TOKEN` is optional. When it is empty, a bearer header never authenticates.
- Five failed logins per ten minutes is the limit, counted in this process only.
- No new dependency.

## Known gaps

- Market reads are still reachable without a cookie if something else forwards the port. Closing that means opening the port only via the paths in `docs/remote-access.md`.
- The rate limit is in memory. A restart clears it.
- CI on this branch is the `main` workflow (ruff and pytest). The gitleaks / mypy / pip-audit job lives on `jarvis/nse-001` and is not in this diff.

## Security impact

An anonymous caller can no longer hit the kill switch, the keys API, settings, tables, books, the today or strategies admin views, quote refresh, or universe edits. Those return 401. The listener stays on `127.0.0.1` unless the operator sets `EXPOSE_HTTP=true`. Password and token checks do not use `==`. Live trading stays off.

## Rollback

Check out `main`. The engine returns to the previous bind (`WEB_HOST`, default `127.0.0.1`, with no extra flag) and the previous auth gates. Do not deploy this branch. To drop the remote branch later, delete `jarvis/nse-002` without force-pushing `main`.
